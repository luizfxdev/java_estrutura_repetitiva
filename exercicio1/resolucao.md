# Explicação do Programa: Números Ímpares até X

## Código atual

```java
import java.util.Scanner;

public class ImparesAteX {
    
    public static void main(String[] args) {
        
        try (Scanner sc = new Scanner(System.in)) {
            int x = sc.nextInt();
            
            for (int i = 1; i <= x; i++) {
                if (i % 2 != 0) {
                    System.out.println(i);
                }
            }
        }
    }
}
```

## ?? Conceito: Loop FOR

### O que é um loop?

Um **loop** (ou laço) é uma estrutura que **repete um bloco de código** múltiplas vezes.

**Sintaxe do for:**
```java
for (inicializacao; condicao; incremento) {
    // código que se repete
}
```

---

## Estrutura do FOR

### `for (int i = 1; i <= x; i++) {`

Quebra em 3 partes:

| Parte | Significado | Exemplo |
|-------|-------------|---------|
| **Inicialização** | Valor inicial | `int i = 1` |
| **Condição** | Enquanto verdadeira, repete | `i <= x` |
| **Incremento** | Aumenta após cada volta | `i++` |

### Passo a passo (X = 8)

```
Iteração 1: i = 1, condicao (1 <= 8) = true ? executa bloco
Iteração 2: i = 2, condicao (2 <= 8) = true ? executa bloco
Iteração 3: i = 3, condicao (3 <= 8) = true ? executa bloco
Iteração 4: i = 4, condicao (4 <= 8) = true ? executa bloco
Iteração 5: i = 5, condicao (5 <= 8) = true ? executa bloco
Iteração 6: i = 6, condicao (6 <= 8) = true ? executa bloco
Iteração 7: i = 7, condicao (7 <= 8) = true ? executa bloco
Iteração 8: i = 8, condicao (8 <= 8) = true ? executa bloco
Iteração 9: i = 9, condicao (9 <= 8) = false ? sai do loop
```

## Teste de número ímpar

### `if (i % 2 != 0) {`
Testa se `i` é **ímpar**.

**Lógica:**
- Se `i % 2 == 0` ? número é **par** (resto 0)
- Se `i % 2 != 0` ? número é **ímpar** (resto 1)

### Dentro do if

### `System.out.println(i);`
Se o número é ímpar, imprime na tela.

## Operador de incremento: i++

### O que significa `i++`?

`i++` é equivalente a `i = i + 1`

**Exemplos:**
```java
i = 5;
i++;  // Agora i = 6

i = 10;
i++;  // Agora i = 11
```

### Outras formas de incremento

| Notação | Equivalente | Quando usar |
|---------|-------------|------------|
| `i++` | `i = i + 1` | **Mais comum** |
| `++i` | `i = i + 1` | Em loops (similar) |
| `i += 1` | `i = i + 1` | Mais explícito |
| `i += 2` | `i = i + 2` | Incremento diferente |

---

## Estrutura FOR vs WHILE

### FOR (mais conciso)

```java
for (int i = 1; i <= x; i++) {
    System.out.println(i);
}
```

### WHILE (mais explícito)

```java
int i = 1;
while (i <= x) {
    System.out.println(i);
    i++;
}
```

**Ambos funcionam igual**, mas `for` é melhor quando você sabe quantas vezes vai repetir.

## Lógica: Como identificar ímpares?

### Método 1: Usar módulo (%)

```java
if (i % 2 != 0) {  // ímpar
    System.out.println(i);
}
```

### Método 2: Incrementar de 2 em 2

```java
for (int i = 1; i <= x; i += 2) {  // Pula números pares
    System.out.println(i);
}
```

Ambos funcionam! A segunda forma é mais eficiente (menos iterações).

## Resumo dos conceitos

- **Loop FOR**: repete um bloco de código múltiplas vezes
- **Inicialização**: valor inicial da variável de controle
- **Condição**: enquanto verdadeira, continua repetindo
- **Incremento**: aumenta a variável após cada volta
- **Operador %**: módulo (resto da divisão)
- **Ímpar**: resto 1 quando dividido por 2 (`% 2 != 0`)
- **i++**: incrementa 1 (equivalente a `i = i + 1`)

Se você quisesse melhorar este programa:

import java.util.Scanner;

public class ImparesAteX {
